# ying-skills

通用 AI Coding Skills 仓库。

## Skill Groups

- [`code-engineering/`](./code-engineering/) — 面向真实代码项目的工程治理、架构分析、重构、验证与 Review Skill Group。

`code-engineering` 以 **Refactoring、Clean Code、Module-first、分层架构、Ports/Adapters、Strategy、Plugin、结构化注释与文档、Evidence-based Verification** 为默认工程基线，同时优先尊重目标项目已经明确且合理的架构与规范。
